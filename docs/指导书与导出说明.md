# 指导书与数据导出

## 指导书

打开时覆盖当前主窗口所在屏幕，默认按比例完整展示图片。支持上一页、下一页、放大图片、缩小图片、滚轮缩放和拖动；“适应窗口”恢复完整展示，Esc 关闭。

仅展示当前 PLC 产品名对应文件，不回退到通用或其他产品。文件放在配置的 InstructionDir 中，支持 PNG/JPG/JPEG/BMP/GIF，例如当前产品 `HT11-ACBARBUS`：

- `HT11-ACBARBUS.png`
- `HT11-ACBARBUS_1.png`、`HT11-ACBARBUS_2.png`
- `指导书_HT11-ACBARBUS_第1页.png`、`指导书_HT11-ACBARBUS_第2页.png`

空产品名、无匹配文件时提示无指导书；产品名必须完整匹配，不能只用部分型号。

## 产品查询和导出

产品下拉列表在启动和每次展开时读取当前运行配置指向的 SQLite 数据库，展开刷新保留已选产品，并提供“全部产品”。

点击“导出 CSV”按当前起止日期和产品条件流式读取全部记录（不受当前 500 行分页限制），选择保存位置后导出。列顺序与表格一致，时间在最前；UTF-8 BOM 编码支持中文。空结果生成仅含表头的文件并显示 0 条，失败显示错误，不覆盖原目标文件；退出时取消未完成导出。查询/导出在后台执行，不占用 UI 线程等待全量数据。

大批量数据请按日期分段导出；Excel 单表无法容纳五年约 365 万行。导出固定开始时的最大记录 ID，但期间已存在记录的测试值仍可能更新，因此不是严格同一时刻事务快照；审计导出应使用静止备份。

CSV 文件保留五位批次号文本，但 Excel 直接双击可能自行转为数字；需保留前导零时通过 Excel“从文本/CSV”导入并将批次号列设置为文本。外部文本中的公式起始符会加单引号防止公式执行。
