# 安装与升级（1.2.1）

适用于 Windows x64，需预装 .NET Framework 4.7.2 或更高版本。

运行 `LianDianDataCollection-Setup-1.2.1-x64.exe`。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\LianDianDataCollection`，创建桌面和开始菜单快捷方式。

首次启动前修改安装目录下 `config\app.ini`，将 PLC 地址从默认的 `127.0.0.1` 改为现场地址，并核对点位和字符串编码。建议将数据库 `FilePath` 和备份 `BackupDirectory` 设置为固定的绝对路径。原调试版数据库不会自动复制，请停止旧程序后配置指向原数据库，避免新建空库。

升级请选择原安装目录。已有配置不会覆盖，数据库、日志和作业指导书不打包进安装程序；卸载保留配置和运行数据。产品图片放在 `ProductPIC`，作业指导书放在 `Instruction`。

后续构建的安装包将自带 `DH280GM.png`、`DH280TM.png`、`ES11.png` 三张产品图片，原图保存在 `assets/ProductImages`。安装到 `ProductPIC` 时只补充缺失文件，不覆盖现场同名图片，卸载也保留这些图片。此规则不改变已经发布的 1.1.0 安装包。

本安装包未进行数字签名。安装后不会自动启动或连接 PLC。请在现场确认配置和数据库路径后启动程序。

构建：安装 Inno Setup 6，运行 `tools\BuildInstaller.ps1 -Compiler <ISCC.exe完整路径>`。
