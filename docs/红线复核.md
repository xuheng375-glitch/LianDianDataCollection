# 红线复核记录

> 依据：开发计划 v2.0 §2.4 硬性红线　|　复核对象：重建后的 LianDianDataCollection 源码

## 红线 1：寄存器地址 / 数据类型 / 点位定义零变更

| 检查项 | 位置 | 结论 |
|---|---|---|
| D4000 心跳位（仅写，不读） | `RegisterMap.D4000_Heartbeat`；`PlcService.PollBlocks` 不含 4000；业务仅 `WriteDInt` | ✅ 一致 |
| D4002/D4004/D4006 批次点位 | `RegisterMap` 常量与 §5 表逐字一致 | ✅ 一致 |
| D4008/D4010/D4012/D4014 耐压点位 | 同上 | ✅ 一致 |
| D4016/D4018/D4020/D4022 气压点位 | 同上 | ✅ 一致 |
| D4024 工号（WORD 读低字） | `PlcService.TryGetWord`，快照块 23 寄存器（4002..4024），未扩到 D4025 | ✅ 一致 |
| D5000/D5100/D5200/D5300/D5400/D5500/D5600 字符串区 | `RegisterMap.StringRegisterCounts` + 快照块 | ✅ 一致 |
| 逻辑 D → 物理偏移公式 | `RegisterMap.ToModbus = D - 1 + Offset`（INI 可配，不写死） | ✅ 一致 |

## 红线 2：业务判定逻辑与标志位赋值规则零变更

| 规则 | 实现位置 | 结论 |
|---|---|---|
| 心跳 0-1 反转，PLC 或 DB 掉线停发、恢复复发 | `HeartbeatService.TickOnce`（门控 `_plc.IsConnected && _dbHealthy()`） | ✅ 一致 |
| 批次下发 D4002=1 → 写 D4004/D4006 → 读工号/产品名 → 插空记录 → D4002=2 | `BatchService` | ✅ 一致 |
| 重复键幂等（不重复插入、不报错） | `BatchService` 捕获 `DuplicateKeyException` → 标志位=2 | ✅ 一致 |
| 耐压/气压三方比对（产品+日期+批次）不一致 → 保持标志位=1 | `ExistsByProduct` → `DataMismatch` | ✅ 一致 |
| 历史数据已存在（结果字段非空）→ 标志位=3 + UI 警示 | `HasWithstandData/HasPressureData` → 写 3 | ✅ 一致 |
| 正常上传 → UPDATE 同批次记录（不 INSERT 独立测试表）→ 标志位=2 | `UpdateWithstand/UpdatePressure` 单表模型 | ✅ 一致 |
| 结果 1=OK 绿 / 2=NG 红 | UI 徽章渲染（`TestResult` 枚举） | ✅ 一致 |

## 结论

重建代码对 §5 寄存器表与 §2.4 红线实现零变更；新增内容仅为架构/容错/UI 视觉层（玻璃拟态），未触碰业务规则。
