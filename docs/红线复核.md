# 红线复核记录（2026-09-10）

本页替代旧点位布局说明。依据当前 RegisterMap 与 PLC点位表；不代表现场 PLC 联调已经通过。

## 点位及协议

| 用途 | 当前点位与约定 |
|---|---|
| 心跳 | D4000，DINT，纯写0/1反转；不轮询 |
| 批次下发 | D4002=1；校验D5000产品名称、D4030完整DINT工号非零；写D5700日期、D4100五位批次号，记录入库后回复2；不读取二维码等级 |
| 耐压 | D4010标志、D4014结果；D4200批次、D5800日期、D5100产品、D5300电压、D5400电阻、D5500电流 |
| 气密 | D4020标志、D4024结果；D4300批次、D5900日期、D5200产品、D5600气密值 |
| 二维码 | D4004=1时直读D4400批次、D6100日期、D6000等级、D6200产品；同批绑定入库后回复2 |

标志及结果按DINT双寄存器读取；D4030+D4031完整读取员工号，不能只读低字。其他以上批次、日期、产品与测量文本均为STRING。

## 不变的业务规则

- 耐压、气密按日期+批次+产品精确匹配；不匹配保持1并告警；正常入库回复2；无待应答ACK的历史数据回复3。
- ACK待应答记录用于重放已提交结果，不能当作同批重测覆盖入口；PLC离开等待态后协调清理残留ACK，清理失败继续重试。
- 二维码同等级重传幂等；不同等级或找不到匹配行保持1，不自动覆盖、不自动回复3。
- 未绑定数量只按耐压结果为空统计，不包含气密和二维码，不置顶。
- 产品列表查询product_catalog；下拉展开异步刷新当前目录，不扫描全部历史批次。
- 数值支持科学计数法；非法、溢出、非零下溢到零均拒绝。没有额外增加负数或量程限制。
- 重复故障告警30秒限流，不降低业务重试频率；恢复清除限流状态。主库数据不按备份保留天数清理。

## 现场仍需验证

- PLC按DINT写完整标志值，正确配置WordOrder及ModbusOffset；员工号高字允许非零。
- 请求期间保持整组数据稳定，收到应答后按约定回落再发起下一请求。
- 断电、断网、ACK重放、跨日以及二维码不同等级冲突后的人工处理。
- 当前BatchResetTime为00:00:00；非零重置时间与同批重测属于另行确认的业务范围。
