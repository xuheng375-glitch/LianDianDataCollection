# 联电数据收集 操作说明

> 面向现场操作员　|　版本 v1.0

## 1. 开机与启动

1. 依次给 PLC、工控机、显示器上电。
2. 双击桌面「联电数据收集」图标（或按公司开机流程启动）。
3. 程序全屏启动，顶部显示：**PLC、数据库、心跳** 三个状态灯。
   - 常亮呼吸 = 正常；熄灭 = 掉线，系统自动重连，请勿反复重启电脑。

## 2. 日常操作

### 查看当前批次

界面左侧「当前批次」显示：批次号（6 位）、产品名称、员工工号、日期编码。产品图片会自动匹配显示（以 PLC 下发的产品名为准）。

### 查询测试记录

1. 在右侧选择开始日期 / 结束日期；
2. 产品名称可直接输入过滤，也可下拉选择；
3. 点「查询」，下方表格显示：批次日期、批次号、产品名称、员工工号、电压、电阻、电流、耐压结果、气压、气压结果、时间。
4. 结果徽章：**绿色 OK=合格，红色 NG=不合格**；空字段显示 `--`（该测试尚未上传或未做）。

### 查看作业指导书

点顶部「作业指导书」，按当前产品名过滤显示；无匹配时显示全部。支持翻页、滚轮/按钮缩放、按住图片拖动。

## 3. 警示条与报错

界面底部出现 ⚠ 警示时：

| 提示 | 含义 | 处理 |
|---|---|---|
| 比对不一致 | 上传数据的产品/日期/批次与记录不符 | 核对 PLC 侧数据与当前批次 |
| 历史数据已存在（标志位=3） | 该批次测试数据已记录，重复上传 | 到 PLC 侧清除标志位后重试 |
| 批次下发异常 | 通讯/数据库问题 | 查看 Logs 日志，联系工程师 |

## 4. 换班 / 下班

1. 确认本班批次全部测试完成并已上传（查询核对）。
2. 点「退出」关闭程序，再按流程关机。
3. 不要直接断电；程序会自动持久化数据到本机 SQLite 文件，断电前退出可避免单据未完成。

## 5. 注意事项

- 不要修改 PLC 寄存器地址和业务标志位（1/2/3 语义），由工程师维护。
- 产品图片命名须与 PLC 产品名一致（如 `HT11-ACBARBUS.png`），否则无法匹配。
- 若界面长时间无响应，联系工程师处理，不要强行断电。
