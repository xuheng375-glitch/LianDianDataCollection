## 测试前准备

1. 在运行程序目录的 `config/app.ini` 中填写真实 PLC 的 IP、端口和站号。当前 IP 为本机占位地址，尚未配置现场设备。
2. 确认可安全进行心跳和批次下发写入，再启动通信；测试过程中由现场人员控制 PLC 标志位。
3. 记录 ModbusOffset、WordOrder、StringLowByteFirst、StringEncoding 及字符串占用寄存器数。默认批次号/日期为 3 个寄存器，二维码等级为 1 个，无长度头；必须与 PLC 工程一致。
